# Course image proposals

`course-learning.png`, `course-accounting.png` and `course-typing.png` are newly generated illustrative course artwork for this design preview. They share a navy, graphite and champagne-gold visual style. They do not depict the institute's classrooms or claim to show actual software interfaces.

`rehaan-mark.svg` is a local RC learning monogram for the proposed header, footer and favicon.

These assets are preview-only. The original public course definitions and production assets are unchanged.
